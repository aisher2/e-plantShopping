# Paradise Nursery Shopping Application

**Paradise Nursery** is an online plant shop built with React and Redux Toolkit.

## Overview

Paradise Nursery lets customers browse a curated catalog of houseplants, add them to a shopping cart, and manage their order before checkout.

## Features

- **Landing page** with a background image, the company name, a short description, and a **Get Started** button.
- **About Us** section describing the company's mission.
- **Product listing page** with 18 houseplants grouped into three categories (Air Purifying, Aromatic, Low Maintenance), each showing a thumbnail, name, description, and price.
- **Add to Cart** buttons that add the plant, disable themselves once the plant is in the cart, and update the cart count.
- **Navbar** with links to Home, Plants, and Cart, plus a cart icon showing the total number of items.
- **Shopping cart page** showing each plant's thumbnail, name, unit price, quantity, and subtotal, with buttons to increase, decrease, or delete items, the total cart amount, a **Continue Shopping** button, and a **Checkout** button (Coming Soon).

## Tech stack

- React 18 + Vite
- Redux Toolkit / React Redux
- GitHub Pages for deployment

## Run locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```
